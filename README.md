Cross-wiki recent changes is a web tool that will display the recent changes feed of multiple MediaWiki websites on one page, with optional notifications for when new edits come in.

It is a fork of GlobalRecentChanges by Dentonius on Wikimedia. https://meta.wikimedia.org/wiki/User:Dentonius/scripts/GlobalRecentChanges.js

# Known issues
- When one wiki fails to load, the rest of the program halts
- Edits that happen on the same second will render in the wrong order
- Some wikis are not compatible due to their DDoS protections
